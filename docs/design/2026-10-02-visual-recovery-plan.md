# 视觉回正方案：恢复「深棕卡统一底板」原版方向

更新：2026-10-02  
性质：调整方案（尚未改代码）  
依据：`表哥懂设计_网站制作完整流程与提示词.pdf` 成品截图（P18/21/22/23/25/26）+ 当前 `site/` 实现对照

---

## 一、先说结论

你的判断是对的。

**首页（角色 IP / 深棕卡）做对了**；从「个人介绍」开始，整站被错误地改成了**浅米色杂志排版风**，和原版 PDF「同一张深棕军绿做旧墙，人物 IP 站在墙前演完整个网站」的方案完全不是一回事。

原版 PDF 的核心不是「做一个作品集模板」，而是：

> **一张统一背景 + 同一个角色 IP + 按剧情分场**  
> 文字排版可以参考网页参考图，但**背景永远不换**。

P08 原文甚至专门纠过这个错：

> 「参考图只参考文字排版，**不要背景**，统一视频里的背景，保持背景不变」

当前实现把「网页参考图的浅色排版气质」误当成了整站皮肤，于是首页之后全跑偏了。

---

## 二、原版 PDF 的视觉基因（必须恢复）

### 1. 统一底板（最重要）

| 元素 | 原版做法 | 当前错误做法 |
|---|---|---|
| 背景 | 全站同一张深棕/军绿做旧墙，带颗粒、暗角、暖光 | 首页深棕；之后变成 `#efeee1` / `#f5f2e7` / `#e8eada` 浅米色块 |
| 人物 | 每场都有完整角色 IP，是**主角** | 降级成 20%–34% 透明度水印（`mix-blend-mode`） |
| 卡片 | 米白卡片**浮在深棕底板上**（文件夹页三张分类卡） | 页面本身就是浅色纸，卡片反而没有舞台 |
| 分场 | 首屏 → 履历 → 文件夹 → 作品 → 坠落结尾，同一房间换姿态 | 板块之间换背景色，像换了一个网站 |

### 2. 原版五场剧情（PDF P2 / P17 / P25 / P21 / P23 / P26）

```text
01 头图封面   人物正面追视，深棕墙
02 个人履历   人物侧身讲解，DESIGN.TEACH.BUILD.，年份大字
03 作品文件夹 人物沙发+电脑，中间文件夹，三张米白分类卡
04 项目展示   同一底板压暗，作品大图横滑
05 页脚结尾   人物坠落场景收尾
```

### 3. 原版排版语言（可保留，并已部分做到首页）

- 大号压缩无衬线英文标题：`A FOLDER FULL OF IDEAS.` / `SELECTED WORKS.` / `DESIGN.TEACH.BUILD.`
- 中文小字作副标题，不抢英文主标题
- 左右分栏：标题在左，人物在右（或人物在右下、文件夹在中）
- 强调色：暖金/琥珀（文件夹）、奶油字色
- 编号系统：`01 02 03`、`BIAOGE / SELECTED WORK`

### 4. 取色（从原版截图与现有 hero 素材采样）

| 用途 | 色值 | 说明 |
|---|---|---|
| 墙体基色 | `#2C2522` → `#33301C` | 深棕偏军绿，带颗粒 |
| 墙体中调 | `#4D4D2C` / `#68614C` | 暖光晕、做旧块 |
| 正文字色 | `#E8E8D9` / `#EDE8D8` | 奶油白 |
| 次级字 | `#A8A88A` / `#8B8B6E` | 灰绿小字 |
| 强调（黄绿） | `#D3E49C` | 当前 hero 已用，保留 |
| 强调（暖金） | `#E0B86E` | 文件夹/年份，原版琥珀 |
| 米白卡片 | `#F4F0E2` | 只用于浮在墙上的卡片，不作整页底 |
| 卡片墨色 | `#243024` | 卡片内深绿字 |

**硬规则：整站正文背景只有深棕墙；浅色只允许作为「墙上的卡片」出现。**

## 三、当前问题清单（按严重程度）

### P0 — 背景体系错误（必须改）

| 板块 | 当前 | 应改为 |
|---|---|---|
| `.hero` | 深棕墙 ✅ | **保持不动** |
| `.about-preview` | `background:#efeee1` 浅米 | 深棕墙 |
| `.journey` | `background:#efeee1` 浅米 | 深棕墙 |
| `.story` | `#293725` 偏绿深色（接近但不统一） | 并入统一墙色，微明暗节奏 |
| `.work` | `#f5f2e7` 浅米 | 深棕墙；作品卡可米白 |
| `.toolbox` | `#e8eada` 浅米 | 深棕墙 |
| `.contact` | `#34442c` 深绿 | 并入统一墙色 |
| `.footer` | `#e1e3d2` 浅米 | 深棕墙收尾 |
| `dialog` | `#f4f2e7` 浅米 | 深棕墙上的米白卡，或整块深棕 |

### P0 — 角色 IP 降级（必须改）

当前 `section-ip` / `scene-ip`：

- 透明度 0.12–0.34
- `mix-blend-mode: multiply/screen`
- `blur(1–2px)`
- `saturate(.7)`

结果：人物像**水印**，不像站在房间里的主角。

原版：人物完整、清晰、和文字同级甚至更大，固定在画面右侧/右下，换场只换姿态。

### P1 — 排版气质偏「简历模板」

当前内页标题 `clamp(32px,3.9vw,59px)`、字重 450、大段细正文——这是杂志内页，不是原版的「展板式大标题 + 短句」。

原版每场只讲一句话，英文大标题占半屏，中文两行短文案。

### P1 — 板块过多、叙事被打散

当前：你好 → 介绍 → 经历 → 方法 → 作品 → 工具箱 → 联系（7 场）  
原版：头图 → 履历 → 文件夹 → 作品 → 结尾（5 场）

「工具箱/荣誉」可以保留，但应并入履历或作品场，不单独换一整块浅色皮肤。

### P2 — 转场缺「同一房间」的连续感

原版靠统一背景 + 人物衔接视频。现在没有后续视频，但可用同一底板 + 人物姿态图 + 明暗呼吸过渡，做出「还在同一个房间里」的感觉。

## 四、调整方案（分五步，按顺序做）

### Step 1 · 统一墙色系统（先只改颜色，不动布局）

1. 在 `styles.css` 抽出墙色 token（与 hero 对齐）：

```css
:root{
  --wall-deep:#2c2522;
  --wall-mid:#33301c;
  --wall-warm:#4d4d2c;
  --wall-lift:#68614c;
  --cream:#e8e8d9;
  --cream-soft:#d5d2c0;
  --accent-lime:#d3e49c;
  --accent-gold:#e0b86e;
  --card:#f4f0e2;
  --card-ink:#243024;
}
```

2. 给 `about-preview / journey / story / work / toolbox / contact / footer` 全部换成统一墙底：

```css
background:
  radial-gradient(ellipse at 70% 20%, rgba(104,97,76,.35), transparent 50%),
  radial-gradient(ellipse at 20% 80%, rgba(77,77,44,.25), transparent 45%),
  linear-gradient(180deg, var(--wall-deep), var(--wall-mid) 40%, var(--wall-deep));
color: var(--cream);
```

3. 浅色只保留给：作品卡、文件夹三张分类卡、对话框内页、时间线卡片。
4. 分节之间用 1px 金色/半透明奶油分割线 + 轻微明暗差，**不要**整页换底色。

**验收：** 从首页滚到页脚，任意位置截图，背景都是同一族深棕墙，只允许明暗呼吸，不允许出现大面积米白纸。

### Step 2 · 把人物 IP 请回舞台

1. 去掉 `multiply/screen` 水印逻辑；改为**不透明、清晰**的人物层。
2. 默认构图（对齐 PDF）：人物占右侧约 40%–48% 宽，底部对齐，允许轻微出画。
3. 文字避让：左侧 45%–50% 给标题文案；必要时加与墙色一致的微渐变遮罩保证可读，而不是压暗整个人物。
4. 分场姿态对应：

| 场 | 现有图 | 处理 |
|---|---|---|
| 首屏 | `hero-poster` + 追视视频 | 不动 |
| 介绍/履历 | `ip-journey.png` / `ip-about.png` | 作讲解姿态，右侧完整露出 |
| 作品 | `ip-work.png` | 沙发工作姿态，对齐 PDF 文件夹场 |
| 方法 | `ip-story.png` | 可弱化一点，但仍清晰，不作水印 |
| 联系 | `ip-contact.png` | 保持，接结尾 |
| 结尾 | （暂无坠落视频） | 用最后一张 IP + 墙色渐隐 + 联系信息收束；有坠落素材再替换 |

5. 滚动时只做克制的位移/淡入，禁止再 `blur` 到看不清。

**验收：** 任一内页，用户能立刻认出「还是那个角色站在那面墙前」。

### Step 3 · 排版回到「展板语言」

每场固定结构（对齐 PDF）：

```text
[小标 overline]   BIAOGE / BIOGRAPHY
[英文大标题]      DESIGN. TEACH. BUILD.
[中文短句]        2 行以内
[内容模块]        时间线 / 文件夹 / 作品
[人物]            右侧
```

调整点：

1. 英文主标题加大到接近 hero 的量级（`clamp(40px,5.5vw,84px)`），字重偏 display，可沿用 hero 的 Georgia 衬线或换成更紧凑的粗无衬线（二选一，全站统一）。
2. 中文描述压缩：每场不超过 2–3 个小段，删掉杂志式长段。
3. 「01 / ABOUT」这类 section-label 保留，颜色改为奶油/半透明，不要浅灰。
4. 时间线、技能表在深棕底上改为：左侧金色年份、奶油正文、深绿半透明卡片。

**验收：** 扫一眼页面，每场只被一个大标题抓住；不是满屏小字。

### Step 4 · 文件夹场与作品场对齐原版

**文件夹场（对齐 PDF P21/P22）**

- 深棕墙；
- 标题在上：`A FOLDER FULL OF IDEAS.` / 「打开我的作品夹」；
- 中间是文件夹主体（可保留现有 CSS 立体文件夹，但**改成原版的暖金琥珀色** `#e0b86e`，不是现在的草绿）；
- 点击展开后：三张**米白分类卡**浮在墙上，背景与人物微虚化但不消失（P12）；
- 人物 `ip-work.png` 在右下，沙发+电脑。

**作品场（对齐 PDF P23）**

- 同一墙色**压暗一档**（不是变成纯黑或浅灰）；
- 作品大图是主角，铺满展示区、无白框（P14）；
- 标题：`SELECTED WORKS.`；
- 分类 chip 在深棕上用描边+奶油字，选中态用金/黄绿。

**案例弹窗**

- 遮罩：墙色半透明 + 模糊，不是黑底；
- 面板：米白卡片或深棕卡二选一，全站统一（建议深棕卡 + 奶油字，更贴原版）。

### Step 5 · 转场与结尾

1. 场与场之间：人物轻微上移/转场淡入，背景连续，禁止闪黑、禁止换色块。
2. 页脚结尾：对齐 PDF P26「坠落场景」气质——墙色最深一档，人物大幅居中或偏右，联系方式压在下方；没有坠落素材就用 `ip-contact.png` 放大 + 墙色 vignette。
3. 导航（01 你好 / 02 经历 / 03 作品）可扩展为 04 作品集 / 05 联系，但仍吸附在墙色顶栏上。

## 五、明确「保留 / 修改 / 重做」

| 项 | 处理 |
|---|---|
| 首屏 hero 追视、字文、墙色 | **原样保留**（用户已认可） |
| 人物素材、方向图、P06 视频 | **不重做** |
| 履历/项目文字内容、CMS | **不动**（只换皮） |
| 内页背景色体系 | **重做**（浅米 → 深棕墙） |
| 内页人物呈现方式 | **重做**（水印 → 主角） |
| 内页标题字号与文案密度 | **重做**（杂志 → 展板） |
| 文件夹配色 | **修改**（草绿 → 暖金） |
| 作品卡、弹窗 | **修改**（保持功能，换皮肤） |
| 滚动叙事 `.story` | **保留结构，换皮** |
| CMS / 测试 / 部署 | **不动** |

## 六、建议实施顺序（工作量）

| 阶段 | 内容 | 预估 | 风险 |
|---|---|---|---|
| A | 全站墙色 token + 各 section 换底 + 浅色收束到卡片 | 小 | 低 |
| B | 人物 IP 从水印改主角构图 + 文字避让 | 中 | 中（与文案抢位） |
| C | 展板式标题层级、各场文案压缩 | 中 | 中（需删文案） |
| D | 文件夹暖金 + 作品压暗 + 弹窗统一 | 小 | 低 |
| E | 转场呼吸、结尾坠落感、移动端复核 | 小 | 低 |
| F | 对照 PDF 六页截图逐场目视验收 + 回归测试 | 小 | 低 |

**推荐一次做完 A→E**，否则中间态会一半深棕一半浅米，更乱。

## 七、验收标准（做完后对照）

1. 首页滚到页脚，背景始终是同一族深棕做旧墙。  
2. 每场都有清晰可见的角色 IP，不是水印。  
3. 浅米色只出现在「墙上的卡片/弹窗」里。  
4. 每场一个英文大标题 + 两行内中文，扫读负担明显下降。  
5. 文件夹为暖金琥珀色，展开后三张米白卡；作品图无白框。  
6. 与 PDF P25（履历）、P22（文件夹）、P23（作品）、P26（结尾）并排看，能认出是同一套设计语言。  
7. 功能不回退：追视、文件夹、筛选、案例切换、CMS 发布仍可用；`npm test` 通过。

---

## 八、一句话方向（给后续实现用）

> **不要再做「浅色杂志作品集」。做回「深棕做旧墙上的角色舞台剧」：一张墙、一个 IP、五场戏、米白卡片当道具。首页已经是了，后面全部向首页对齐。**
