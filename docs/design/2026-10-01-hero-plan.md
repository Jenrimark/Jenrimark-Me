# Step 3 首屏实现计划

## 已获授权的范围

用户已确认完整网站模块与先可运行再逐模块验收的路线，2026-10-01 观看 P06 预览后回复「很不错，下一步继续吧」。本次实现首屏、追视与回正，并留出下一模块入口。作品、履历、CMS 与发布按后续模块进行。

## 设计

沿用冻结的灰豆绿复古背景、黏土人物与自然闭口表情。桌面为满屏人物舞台、两侧少量暖白大字与底部导航；移动端为不裁掉头顶的肖像与上下排列文字。交互说明简短，真实身份文案从用户确认的来源填入。

默认纯 HTML/CSS/ES modules，无第三方运行时。页面位于 `site/`，静态资源位于 `site/media/`，可独立部署；当前只在 127.0.0.1 本地预览。

## 文件与任务

- [x] 冻结已通过的静音视频，记录 SHA256、恢复记录与实际帧时间。
- [x] `site/index.html`、`site/styles.css`：首屏、导航、移动适配、下一模块说明。
- [x] `site/gaze-math.mjs`、`site/gaze.mjs`：实际方向时间映射、指针跟随、鼠标离开与滚动时回正、触屏/减少动态效果回退、素材错误回退。
- [x] `site/tests/gaze-math.test.mjs`：方向映射、中心死区、边界值等独立行为测试，先验证失败再实现。

- [x] 浏览器验证桌面与窄屏，检查控制台、指针四向、回正、正常链接与无横向溢出。
- [x] 保存检查证据、更新 brief，在本地打开首屏供用户逐模块验收。

## 素材边界

首屏只使用获批视频及它的帧，不重新生成角色。主滚动叙事、履历衔接、文件夹视频尚不存在，不能冒称素材已齐。下一模块在本轮只提供明确的占位边界；已有站点内容须用户确认来源后才能填入。真实年份、经历和项目成果不推测。

## 验收

鼠标在画面右/上/左/下时人物朝对应方向；中心、鼠标离开、滚动后回正。触屏显示完整静态人物并提供主动播放；减少动态效果时不自动追视。页面在桌面和手机可读、无横向滚动；视频故障仍显示正面图。进入下一模块前按原流程由用户验收。
