- 手感：**轻、快、跟手**（像 Awwwards 作品集，不是 PPT 切页）

## 三、页面结构（单页五幕）

### 幕 1 · Hero（约 100vh）
- 媒体：`hero-seek.mp4` / `p06-approved.mp4`（追视素材）
- 交互：**鼠标在首屏移动 → 人物头部/视线跟随**（沿用 gaze 逻辑：上下左右切帧或 seek）
- 文案：超粗英文大标 `HELLO.` / 中文副标
- 滚动提示：底部微动「向下滚动」
- 离开首屏后：停止追视，视线回正，再进入场景区

### 幕 2–5 · 四张场景（每幕约 80–100vh）
| 幕 | 图 | 文案位 | 运镜感 |
|---|---|---|---|
| 2 | `S01-journey.png` | 右侧讲解，字放左 | 微微推近 / 视差 |
| 3 | `S02-sofa.png` | 左侧留白 | 轻微下移+缩放 |
| 4 | `S03-folder.png` | 左上大留白 | 拉远感（图更小） |
| 5 | `S04-fall.png` | 中上标题 | 轻微加速下沉 + 结束收束 |

每幕 = **一张全屏底图 + 一层文案**，幕与幕之间用 **交叉淡入 + 轻视差**，不闪黑、不硬切。

**衔接视频 T01–T03**：可选，不作为主结构。若要更顺，仅作幕间 0.3–0.5s 的短过场（或先不做，保持最轻）。

## 四、滚动与性能（解决卡顿）

### 1. 砍长度
- 总高度 ≈ **1 + 4 幕 ≈ 450–500vh**（不是 3000vh）
- 一屏一景，滚一下就换场，心理上「很快」

### 2. 不要 video.seek 当主线
| 场景 | 方案 |
|---|---|
| 四张场景 | **静态图 + CSS transform**（scale/translate/opacity），GPU 加速，60fps |
| 首屏追视 | 仅 Hero 一个视频；追视用 **方向帧切换或稀疏 seek**（松手/离开后回正），不要每帧 seek |
| 过场视频 | 默认不做；以后要再加，且只允许 1 个挂载 |

### 3. 滚动驱动
- `requestAnimationFrame` 读 `scrollY`，**只写 transform/opacity**，不写 layout
- 位置用 **阻尼插值**（lerp 0.12–0.18）：跟手又不抖
- `will-change: transform` 加在场景层
- 触摸：尊重原生滚动，不要 `scroll-behavior: smooth` 抢手感（用 JS lerp 时关掉）
- `prefers-reduced-motion`：关掉视差，只保留淡入

### 4. 资源
- 四张图：压缩到 1920 宽 WebP/优化 PNG，`loading="eager"` 仅首屏，场景图 `decode()` 预加载
- 首屏视频：`preload="auto"`；场景无视频
- 移动端：dpr 上限 2，降低 scale 幅度

## 七、验收标准（做完你按这个点）

1. 浏览器里只有**一页**，从上滚到下是连续体验  
2. 首屏鼠标移动，人物视线**跟得上、不橡皮筋**  
3. 一滚就动，**不粘、不顿、不黑屏**  
4. 顺序明确：站立 → 坐下 → 缩小右下 → 坠落  
5. 倒着往上滚同样顺（回放感）  
6. 手机滑动跟手，文字可读  
7. 总滚动长度约半分钟内能到底
