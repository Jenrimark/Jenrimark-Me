# PDF P17–P26 对照差距与回正方案

更新：2026-10-04  
依据：`表哥懂设计_网站制作完整流程与提示词.pdf` 第 17–26 页成品截图

---

## 一、核心结论

深棕墙色已经对了，但 **排版气质和作品场结构** 和原版还差一大截。原版是：

> **超粗压缩无衬线大标题 + 米白卡片浮在深棕墙上 + 人物完整坐在场景里 + 大图作品预览**

当前是：Georgia 衬线标题 + 小图卡片网格 + 人物水印/半隐藏。

---

## 二、逐场差距

### 1. 排版（全站，最影响气质）

| 项 | PDF 原版 | 当前 |
|---|---|---|
| 英文主标 | 超粗压缩无衬线（Druk/Impact 风格），全大写，字重极重 | Georgia 衬线，偏细 |
| 字例 | `SELECTED WORKS.` `A FOLDER FULL OF IDEAS.` `DESIGN.TEACH.BUILD.` | `Selected Works.` 衬线 |
| 字距 | 略负字距，块面感 | 正常 |
| 中文副标 | 小号常规，紧跟英文下 | 有的过大 |

**改法**：`display-en` 与各场 h2 主标改用 `Impact, "Arial Black", "Haettenschweiler", sans-serif`，`font-weight:900`，`text-transform:uppercase`，`letter-spacing:.02em`，`line-height:.95`。

### 2. 导航与页眉（P21/23）

| 项 | PDF | 当前 |
|---|---|---|
| 字标 | `Biaoge.` | `jenrimark® 殇璃` |
| 导航 | 职业首页 / 个人履历 / 作品文件夹 / 作品展示 / 无限可能 | 01 你好 / 02 经历 / 03 作品 |
| 右侧 | `INDEPENDENT DESIGNER` + 小字 | 聊聊想法 |
| 面包屑 | `03 / SELECTED WORK · 作品文件夹` | `03 / SELECTED WORK` |
| 底栏 | `三编 · 界面 · 插画 / 项目从完整视频剪辑 · A-15` | 简单 footer |

**改法**：导航扩为 5 项；每场加 `编号 / 英文 · 中文` 双行面包屑；底栏加分类标签行。字标保留 jenrimark（是本人品牌，不改成 Biaoge）。

### 3. 作品文件夹场（P21/P22）— 结构性差距

PDF 原版：
- 标题 `A FOLDER FULL OF IDEAS.` 居中大标
- **三张米白分类卡**（3D设计 / UI DESIGN / 插画 IP），每张有图 + 标签 + 两行说明 + 小字英文
- 卡片下方一条 **暖金文件夹条** `Portfolio -Bg →`
- **人物完整坐在右下**（沙发 + 电脑）
- 右上「收起文件夹 ×」
- 底部一行小字 `三编 · 界面 · 插画 / 点击展开或按 ESC 收起`

当前：只有一条横向 folder-launch 条 + 2 列作品小图网格，没有「三卡 + 金条 + 人物」舞台。

**改法**：
1. work 场标题改为居中 `A FOLDER FULL OF IDEAS.`
2. 新增 `.folder-stage`：三张米白卡（用真实分类：AI 产品 / 研究实践 / 全栈应用·效率工具）+ 暖金文件夹条
3. 卡片带图标色块 + 分类名 + 两行简介
4. 人物 `ip-work.png` 完整放右下（恢复显示，不再 display:none）
5. 点击文件夹条滚动到作品列表 / 或展开对话框（保留现有 ESC）

### 4. 作品预览场（P23）

PDF 原版：
- 背景**再压暗一档**（近黑）
- 标题 `SELECTED WORKS.` 居中
- **单张大图作品**居中（横屏），左右露出相邻作品
- 底部进度条 + `01 / 08`
- 作品下 `IN-CAR / 车载` 大标 + 一行小字
- 顶部一排分类 chip
- 右上 `SEVEN DISCIPLINES / TWENTY WORKS / SCROLL TO EXPLORE`

当前：2 列小图卡片网格，信息密度低，不像展台。

**改法**：
1. 作品区改为**大图轮播**：中间一张大卡（16:10），两侧露出相邻卡
2. 底部进度条 + `01 / 08` 计数
3. 作品标题改为 `中文名 / 分类` 大标
4. 分类 chip 保留，改为顶栏一排
5. 保留点击进详情

### 5. 履历场（P25）

PDF 原版：
- `DESIGN.TEACH.BUILD.` 三行超粗大标
- **巨大年份水印** `2009` 半透明
- 时间线单条大卡片（2009-2013 南开大学）
- 人物右侧完整讲解姿态
- 左侧竖排小字列表

当前：时间线有了，但没有年份水印、标题还不够「展板」、人物偏水印。

**改法**：加年份水印层；标题改压缩无衬线；人物恢复完整。

### 6. 结尾（P26）

PDF：人物坠落场景收尾。  
当前：联系区 + 无坠落。  
**改法**：contact 用 `ip-contact.png` 放大居中偏右 + 墙色 vignette；文案 `SAY HELLO.` 保持。有坠落素材再换。
