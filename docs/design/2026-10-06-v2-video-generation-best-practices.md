本文基于以下材料整理：

- PDF 转换得到的原始 Markdown 和文本参考；
- 原始 P02–P06 人物方向图与闭环视频方法；

## 2. 核心工作流

### 2.1 T00 首屏人物追视

T00 不使用“单张正面图直接生成眼动视频”的方式，而采用以下流程：

```text
正面图
→ 右侧方向图
→ 上方方向图
→ 左侧方向图
→ 下方方向图
→ 重复上传正面图作为闭环终点
→ 上传统一墙面背景
→ 生成首尾闭环的头颈与视线运动视频
```

方向图只负责提供头部、颈部、眼球和面部角度。人物身份、身体、服装、画面构图由正面基准图锁定，背景由统一墙面图锁定。

### 2.2 T01–T04 页面动作衔接

页面间视频采用以下流程：

```text
起始场景图
→ 原始动作参考视频或关键帧
→ 目标场景图
→ 统一背景图
→ 必要的道具局部参考
→ 按精确时间轴生成首尾对齐的连续动作视频
```

起始图负责锁定第一帧，目标图负责锁定最后一帧，原始视频负责动作节奏，统一背景负责环境和色彩一致性。

```text

【参考图用途】

@图片6 与 @图片1 是完全相同的文件。@图片6 是视频最后回到正面时的目标状态，不是新的角色，也不是新的背景。

@图片7 是整条视频唯一的背景参考。最终视频的墙面颜色、纹理、颗粒、暗角、光影、明暗分布、清晰度和构图全部以 @图片7 为准。禁止使用 @图片1–@图片6 中的背景。

始终保持同一个东亚小男孩黏土 3D 角色：黑色卷发，脸部小熊、爱心、点赞贴纸，黑色短袖 T 恤，胸前小熊、星星和点赞徽章，哑光黏土材质，柔和电影级布光。

脸型、五官比例、眼睛大小、鼻子、嘴巴、耳朵、头发、贴纸数量、贴纸位置、贴纸颜色、服装轮廓、服装材质和人物比例始终一致。

眉毛保持自然放松，眉心展开，不出现皱眉、额头紧张褶皱或突然改变的表情。

【固定底板】

把 @图片1 的身体、肩膀、胸口、衣领、服装轮廓、手臂和人物位置视为冻结的静态底板。

整条视频中：
- 身体始终正面对画面中心；
- 肩线高度保持不变；
- 衣领中心保持不变；
- 胸口和躯干保持不变；
- 手臂保持不变；
- 人物大小保持不变；
- 人物位置保持不变；
- 不能前倾；
- 不能后仰；
- 不能侧身；
- 不能耸肩；
- 不能呼吸起伏；
- 不能整体上下移动；
- 不能整体左右移动；
- 不能整体缩放。

动作只发生在头部、颈部、眼球、眉毛、眼睑、嘴唇、下巴和面部微表情。

颈部根部固定在 @图片1 的衣领中心。头部只能围绕固定颈根自然转动，不能整体平移，不能靠近镜头，不能远离镜头，不能突然放大或缩小。

【动作逻辑】

动作遵循真实人体观看习惯：眼球先悄悄转向目标方向，经过短暂滞后后，头部和颈部再缓慢跟随；面部表情随着视线自然微调。肩膀只允许有极轻微、自然、非夸张的联动，不能让身体跟着头部大幅运动。

【10 秒精确时间轴】

0.00—0.30 秒：完全保持 @图片1 的正面状态。人物、身体、头部、眼神、表情和背景保持静止。

0.30—1.80 秒：眼球先缓慢向画面右下方移动，头部随后轻微向右下方跟随。保持身体、肩膀、衣领和背景冻结。

1.80—2.80 秒：从右下方向转到画面正右方。头部围绕固定颈根自然转动，面部神态轻微放松。

2.80—3.80 秒：从正右方沿平滑弧线转向右上方。眼球略微提前，头部和颈部随后跟随。眉毛可以轻轻抬起，带一点自然好奇感，但不能夸张。

3.80—4.70 秒：从右上方抬头转向正上方。下巴自然抬起，不能拉长脖子，不能后仰躯干。

4.70—5.70 秒：从正上方沿平滑弧线转向左上方。动作连续，不停顿，不反向。

5.70—6.70 秒：从左上方转向正左方。头部围绕固定颈根转动，身体始终正对画面中心。

6.70—7.70 秒：从正左方转向左下方。眼球先向左下方，头部随后跟随，头部轻轻下沉。

7.70—8.60 秒：从左下方回到正下方。动作缓慢、柔和，不能突然低头，不能身体前倾。

8.60—9.70 秒：从正下方缓慢回到正面。眼球先回到正面，头部和颈部随后回正，表情恢复为自然放松。

9.70—10.00 秒：完全复现 @图片6，也就是与 @图片1 完全一致的正面状态。人物、背景、光线、材质和构图保持静止。

【首尾闭环】

第一帧与最后一帧必须完全一致：人物位置、人物大小、头部角度、眼神、眉形、嘴形、贴纸、背景、墙面纹理、光线和色调全部一致。

这是一个连续的头部和眼动视频，不是静态图片交叉淡入淡出，不是幻灯片，不是镜头切换。

【严格禁止】

禁止镜头推拉、摇移、旋转、裁切、自动对焦、景深变化和镜头呼吸。

禁止背景移动、纹理漂移、颗粒闪烁、墙面重绘、光影跳动、色温变化和曝光变化。

禁止人物整体移动、整体缩放、人物变大、人物变小、人物下移、身体转动、身体侧倾、耸肩、胸口起伏和手臂动作。

禁止展示后脑勺，禁止 360 度扭头，禁止违反人体结构的扭颈。

禁止换脸、变脸、脸型变化、五官错位、眼球抖动、额外眼睛、斜视、眼睛融合、嘴巴融化、牙齿增生、舌头分裂、面部重影。

禁止发型变化、贴纸漂移、贴纸消失、贴纸增加、贴纸互换、衣服变形、衣领移动、材质变形、果冻感、液化和残影。

禁止新增物体、字幕、文字、Logo、水印、音乐、对白、音效、黑场、闪白、淡入淡出和转场。
```
