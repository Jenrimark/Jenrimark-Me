## 2. 本阶段就这一条主提示词

**上传**：`首屏视频.mp4`、`主视频.mp4`（拼好的 main-story）、`网页参考图.jpg`

```text
我要做一个 scrollytelling 网页，核心逻辑:用户滚动页面时 ，主视频进度跟随滚动同步变化(向下滚=前进，向上滚=倒放)。

【素材】首屏视频.mp4:开头首屏跟随鼠标移动而移动(用户未滚动时保持首屏画面)主视频.mp4:主视频(滚动驱动进度)网页参考图.jpg:文字排版参考图

【视频主题/情绪]这条视频想传达的是:一个设计师的作品集介绍网站请分四步完成:【一 、视频叙事拆解】基于上面的主题+主视频.mp4 的画面节奏，拆 3 个关键节奏点，每个节奏点:标注对应主视频.mp4 的时间区间- 写一句有情绪感的中文文案(15-30 字)

建议节奏点（可按拼接后实际时间微调）：
0) 开场 / 人物亮相 — 主视频约 0–8s — 文案示例：「你好，这是我的设计世界。」
1) 讲解 / 作品介绍 — 主视频约 8–18s — 文案示例：「把想法做成看得见的体验。」
2) 坠落 / 结尾 — 主视频约 18–30s — 文案示例：「往下掉也没关系，作品还在。」

【二 、三段式切换逻辑】滚动进度= 0 intro-loop (autoplay loop muted)滚动进度 0-1main(滚动驱动，不 autoplay)滚动进度 0.98 outro-loop (autoplay loop muted)切换实现:· 三段视频同时渲染， 用 opacity 控制显隐- 0.5s fade 过渡，避免硬切- 三个视频都加 playsInline preload="auto" [三、参考图排版应用】先分析 网页参考图.jpg 的排版语言:字体:衬线/无衬线字重对比、是否全大写字号层级： 主标题/副标题/描述的比例对齐方式 ：居左/居中/非对称多栏颜色体系： 主色、强调色、背景色装饰元素：CTA 按钮、标签 、icon 、分割线整体气质：极简/密集/对比强/呼吸感然后把这套排版语言完整应用到每段文案上 ：字体/字号比例/颜色/布局全部还原参考图

【四 、技术实现要求(避坑重点)】技术栈:纯 HTML+ CSS+JavaScript，不用任何框架。视频全屏背景:position:fixed,object-fit:cover主视频必须 muted + playsInline + preload="auto", 不 autoplay页面总高度= main 时长 x100vhscroll 进度(0-1) x main.duration = main.currentTime用 requestAnimationFrame 平滑 seek,避免卡顿文案容器 position:fixed 居中，fade in/out 切换移动端兼容:i0S Safari 必须 playsInline响应式:PC 多栏布局在移动端自动堆叠

【输出】直接输出完整 index.html 文件。
```

## 3. 若要「三段分控」而不是一条长视频

当不想先拼接、或想分别控制 T01/T02/T03 时，用下面加强版（仍属本阶段）：

```text
在刚才的 scrollytelling 页面上，把主视频改成三段式：
T01.mp4 对应滚动 0–0.33（履历讲解）
T02.mp4 对应滚动 0.33–0.66（沙发工作）
T03.mp4 对应滚动 0.66–1（坠落结尾）
三段都 muted + playsInline + preload="auto"，不 autoplay。
当前段用 opacity=1，其他段 opacity=0，交界处 0.4s 交叉淡入淡出。
每段内仍用「段内进度 × 段时长 = currentTime」随滚动前进/倒放。
段切换时保持人物位置连续感，禁止黑场硬切。
文案随段切换 fade：讲解 / 工作 / 结尾。
```
