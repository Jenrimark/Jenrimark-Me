## 执行顺序

1. 三条提示词分别粘贴，上传对应图片编号不要错位  
2. 每条先看 **尾帧是否与目标场景图重合**，再看中段是否抖、跳、换脸  
3. 全链对表：`p06 尾帧 → T01 → S01 → T02 → S02 →（T02b→S03）→ T03 → S04`  
4. 再做双向（倒放）抽检  
5. 单条失败只重做该条，不改 S01–S04 与身份基准  

## 常见失败与改法

| 现象 | 处理 |
|---|---|
| 又戴上眼镜 | 在「严格禁止」前加粗一句：人物不戴眼镜 |
| 尾帧到不了 S0x | 把该帧图再上传一次并写：最后一帧必须完全重合 |
| 人物占屏变大 | 写死：人物高度不得超过画面 30%，四周留白 |
| 沙发/图标乱飞 | 写死道具列表与外圈位置，禁止新增杂物 |
| 首尾跳切 | 加：首帧与上一段尾帧姿态/肩线/背景完全一致 |
