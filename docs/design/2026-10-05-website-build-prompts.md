## 三、P07 生成滚动叙事网页（主指令）

**上传**：首屏视频.mp4、主视频.mp4（或 T01–T03 串成的主叙事）、网页参考图.jpg

```text
我要做一个 scrollytelling 网页，核心逻辑:用户滚动页面时 ，主视频进度跟随滚动同步变化(向下滚=前进，向上滚=倒放)。

【素材】首屏视频.mp4:开头首屏跟随鼠标移动而移动(用户未滚动时保持首屏画面)主视频.mp4:主视频(滚动驱动进度)网页参考图.jpg:文字排版参考图

【视频主题/情绪]这条视频想传达的是:一个设计师的作品集介绍网站请分四步完成:【一 、视频叙事拆解】基于上面的主题+主视频.mp4 的画面节奏，拆 3 个关键节奏点，每个节奏点:标注对应主视频.mp4 的时间区间- 写一句有情绪感的中文文案(15-30 字)

【二 、三段式切换逻辑】滚动进度= 0 intro-loop (autoplay loop muted)滚动进度 0-1main(滚动驱动，不 autoplay)滚动进度 0.98 outro-loop (autoplay loop muted)切换实现:· 三段视频同时渲染， 用 opacity 控制显隐- 0.5s fade 过渡，避免硬切- 三个视频都加 playsInline preload="auto" [三、参考图排版应用】先分析 网页参考图.jpg 的排版语言:字体:衬线/无衬线字重对比、是否全大写字号层级： 主标题/副标题/描述的比例对齐方式 ：居左/居中/非对称多栏颜色体系： 主色、强调色、背景色装饰元素：CTA 按钮、标签 、icon 、分割线整体气质：极简/密集/对比强/呼吸感然后把这套排版语言完整应用到每段文案上 ：字体/字号比例/颜色/布局全部还原参考图

【四 、技术实现要求(避坑重点)】技术栈:纯 HTML+ CSS+JavaScript，不用任何框架。视频全屏背景:position:fixed,object-fit:cover主视频必须 muted + playsInline + preload="auto", 不 autoplay页面总高度= main 时长 x100vhscroll 进度(0-1) x main.duration = main.currentTime用 requestAnimationFrame 平滑 seek,避免卡顿文案容器 position:fixed 居中，fade in/out 切换移动端兼容:i0S Safari 必须 playsInline响应式:PC 多栏布局在移动端自动堆叠

【输出】直接输出完整 index.html 文件。
```

**本项目改法（路线 A）**
- 不要重写整站；在现有 `site/index.html` 增加/替换叙事段
- `主视频` 可用：`T01→T02→T03` 拼接，或继续用 `hero-seek.mp4` + 各场静态图
- 排版直接沿用本站深棕墙 + 压缩粗英文大标

**做完再往下**，先别一次改完所有模块。

## 四、P08–P10 首屏精修（写在当前网页任务里）

### P08 统一背景与首屏追视

```text
纠正 ：参考图只参考文字排版，不要背景，统一视频里的背景，保持背景不变，或者直接贴我上传的背景图；2.首屏视频是要放在首屏， 已经是人物上下左右看的视频 ，随着鼠标划动而跟随鼠标的位置移动首屏视频里的人物头部，要根据主视频来区分板块，不能只有一个页面不动
```

**本项目**：本站已有 gaze 追视；重点是「参考图只借排版、背景统一灰豆绿」，并保证滚动分场。

### P09 先回正再进入下一屏

```text
滚轮触发离开首屏后 ，鼠标将停止对人物视线的控制；表情回到初始状态，再衔接下一段人物动画。
```

**本项目**：离开首屏 → 停止追视回正 → 接 **T01**。

### P10 调整水波与黑色拖尾

```text
缩小影响范围 、靠近鼠标的波纹更细、点击时向外扩散 ，去掉黑色拖尾。
```

**验收**：鼠标移/点/停；滚动后先回正再进下一段。

## 五、P11–P12 作品文件夹

### P11 加入蓝幕文件夹动画

```text
请在当前网页的第二页「作品文件夹」页面中加入我上传的蓝幕文件夹视频。要求：1. 去除蓝幕，只保留文件夹动画，清理蓝边和残色。2. 视频透明背景、 自动播放、静音 、循环，不显示播放器控件或矩形背景。3. 将文件夹放在左侧标题与右侧人物之间的留白区域，位置偏下，不遮挡文字、人物和导航。4. 保持原比例并自适应屏幕 ，桌面端宽度约占页面的22%～30%。5. 鼠标悬停时轻微上浮放大，点击后打开现有作品列表。6. 保持网页现有设计、布局、文案和其他动画不变。7. 优先转换为透明WebM；无法转换时，使用Canvas/WebGL 完成蓝幕抠像，不要用普通 CSS 混合模式。
```

**本项目**：文件夹区人物用 **S03-folder.png**（右下缩小）；缺蓝幕文件夹视频时可继续网页原生图形。

### P12 点击展开并突出文件夹

```text
把文件展开效果改为点击触发，文件夹平移到中间 ，三个类目的卡片放大； 以及背景和缩小后的人物都适度虚化，只保留主体文件夹清晰 。并且支持关闭按钮、和 ESC 键收起。
```

**验收**：悬停不误开；点击居中；ESC / 关闭能收起。

## 六、P13–P14 作品预览

### P13 制作作品集预览页

```text
请根据上传的作品素材和参考视频 ，在「作品文件夹」与「无限可能」之间新增作品集预览页。布局和滚动动效参考视频，改为适合横屏作品的展示方式，保持图片比例。背景沿用图三并压暗 ，突出作品。先整理素材，再按「车载 → 运营 Banner→ 品牌全案→ IP 形象→ 插画→ 电商→ 产品渲染」排序 ，每类约两张，同类集中展示，不要混排 ，并配简洁的中英文标题和小字简介。点击作品进入对应案例详情页，展示简介与完整作品大图，支持放大、返回作品集及切换上一个／下一个案例。整体延续现有网站风格。
```

**本项目改法**：分类改为你的**真实项目分类**（本站为 AI 产品 / 研究实践 / 全栈应用等），不照抄教程分类名。  
**注意**：标题说明交给网页排版，不依赖图内小字。

### P14 去掉作品上下白框

```text
请检查作品集预览页，去除图片上下多余的白框，让作品在展示区域内完整铺满，同时保持原始比例，不拉伸、不裁切 ，并延续现有排版和滚动动效。检查作品没有被拉伸，重要内容没有被裁掉；点击后能进入对应详情，能返回作品集，也能切换上一个和下一个案例。
```
